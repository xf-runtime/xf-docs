# T_ZXF_ENTITY — Entity Metadata

`T_ZXF_ENTITY` defines the structure, behaviour, UI, search, and workflow semantics of an entity.  
It is the core metadata object inside xF.

## Identity

### xf_id  
Primary key.

### objectname  
Internal entity name, always prefixed with the app code.

### header  
Human-readable entity name.

### objectdescription  
Description of the entity.

## Application Binding

### app_  
Foreign key to `T_ZXF_APP`.

### app__guid  
GUID version of the FK.

## Entity Type & Behaviour

### isaggregate  
Marks transient entities without physical tables.

### basetable  
Physical table name (uppercase). Auto-generated by xF.

### setinterval  
Auto-post interval (ms).

### isdeletable  
Whether DELETE is allowed.

### iscreateonly  
Only INSERT allowed; no UPDATE.

### isguireadonly  
Read-only in UI.

### islinkedtouser  
Instance is tied to a specific user.

## UI Metadata

### sections  
JSON array defining UI layout.

### section_active  
Active UI section.

### menugroup  
Menu grouping.

### iconclassname  
Icon for UI.

### iscustomui  
Entity uses a custom page.

### formid  
ID of custom page.

### componentpage  
HTML template for rendering.

### xfctrltype  
Control type if entity is a component.

## API & Integration

### uri_external  
Endpoint to send payload copies.

### uri_validation  
Endpoint for validation.

### uri_postcommit  
Endpoint to call after successful save.

### apikey_internal  
Internal API key.

### apikey_external  
External API key.

## Search & Indexing

### stridsql  
SQL to compute string representation.

### instancetable  
Lookup table for string representation and timestamps.

### instancecachecount  
Number of instances to track.

### isindexed  
Enable full-text indexing.

### ftindex_tablename  
Full-text index destination table.

### querymode  
Search mechanism (built-in, SQL, external).

### iscontentmatch  
Search full content or specific fields.

### customquery  
Custom SQL for search results.

### qry_viewcolumns  
Columns to display in search results.

### qry_orderbycolumns  
Columns to order search results by.

### fk_viewcolumns  
Columns to display when entity is shown as child.

## Uniqueness & Validation

### hascompositeuniquecheck  
Enable composite uniqueness validation.

### compositeuniqueproparray  
SQL defining composite uniqueness.

## Morphing / Redirecting

### set_entity  
Target entity for aggregate morphing.

### set_entity_guid  
GUID version of target entity.

## Security

### allowanonget  
Allow unauthenticated GET.

### allowanonpost  
Allow unauthenticated POST.

### deny_get  
SQL expression returning 1 to deny GET.

### deny_set  
SQL expression returning 1 to deny POST.

## Misc

### settings  
JSON object for arbitrary metadata.

### file_id  
Internal use.

### is_sys  
Marks system entities.

### targetelement  
Internal use.
